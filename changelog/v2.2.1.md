## Security

| Tag | Change |
|---:|---|
| ![bugfix] | The server network overview (`/banksystem serverNetworkInfo`: server addresses, ports and online players) is now really limited to BankSystem admins. In 2.2.0 any player on the master, on a single server or on a trusted slave server could still open it |

## Documentation

| Tag | Change |
|---:|---|
| ![improvement] | The guides moved to the new documentation site, [kroia.github.io/BanksystemStockmarketDoku](https://kroia.github.io/BanksystemStockmarketDoku/banksystem/), which covers BankSystem and StockMarket for players, server admins and mod authors. The guide pages in the repository are gone, and the README is now a short overview with a link to the site |

## Internal

| Tag | Change |
|---:|---|
| ![improvement] | The server log now shows progress while BankSystem sets up the item list at server start (a start line with the item count, a progress line about every 5 seconds, and a done line with the number of new items and the time taken), and the same on a slave server while it applies the master's item list, so a long first start on a large mod pack no longer looks frozen |
