## Build & Dependencies

| Tag | Change |
|---:|---|
| ![bugfix] | Minecraft 26.1–26.3: the game crashed at startup because the BankSystem jar was missing its bundled ModUtilities library. ModUtilities is included in the BankSystem jar again, so no separate download is needed. The bundled ModUtilities 2.2.1 also contains the Fabric Permissions API again, which permission mods use on Fabric to grant BankSystem's permission nodes |
