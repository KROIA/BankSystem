# 2.0.6 — In Development

## UI / UX

| Tag | Change |
|---:|---|
| ![feature] | Added an "Allow all items" server setting — when on, the mod's blacklist becomes the sole gate on what can be banked, so admins running large modpacks no longer need to curate an item-by-item allow-list. Off by default; existing worlds keep today's whitelist behavior. |
| ![bugfix] | <details><summary>Currency Bindings screen: provider picker now opens the account picker instead of jumping back to the bindings list on 2+ provider setups</summary><br>With more than one currency mod loaded (e.g. Numismatics **and** Lightman's Currency), clicking a provider tile bounced straight back to the bindings list instead of showing that provider's available accounts. Root cause: the provider button's falling-edge callback both set the next screen and then immediately closed itself back to the parent, clobbering the navigation — the same defect class already fixed in the sibling account picker. Removed the stray close call so the account picker stays on screen.</details> |

## Integrations

| Tag | Change |
|---:|---|
| ![feature] | <details><summary>Bank Upload and Bank Download blocks now connect to modded item-transport systems (PrettyPipes and friends)</summary><br>Vanilla hoppers already worked with the upload/download blocks because they use Minecraft's `Container` interface directly, but modded pipe systems (PrettyPipes on NeoForge, and any Fabric Transfer API consumer such as Modern Industrialization or AE2-Fabric) look for a platform-specific item-handler view and skipped the blocks as "not an inventory." The block entities now expose an `IItemHandler` capability on NeoForge (via `InvWrapper` against `RegisterCapabilitiesEvent`) and an `ItemStorage.SIDED` view on Fabric (via `InventoryStorage.of`). NeoForge tested in-game with PrettyPipes. Fabric registration ships alongside but was not manually tested this session.</details> |

## Build & Dependencies

| Tag | Change |
|---:|---|
| ![bugfix] | JEI is now on the dev-time runtime classpath so contributors running the mod from IntelliJ no longer hit an ASM `TypeNotPresentException` at launch. Players are unaffected — JEI remains a soft dependency at world runtime. |

## Documentation

| Tag | Change |
|---:|---|
| ![feature] | <details><summary>New user guide walks players through binding a bank slot to a Numismatics or Lightman's Currency account</summary><br>`documentation/user-guide/CurrencyBindings.md` covers the full bindings-screen workflow with screenshots: personal vs shared account matching, coin-variant deposits at bank terminals, the three-way unbind choice (keep on BankSystem / keep on provider / cancel), drift behavior when the external balance changes outside BankSystem, per-provider notes for Numismatics and Lightman's Currency, and troubleshooting for item-mismatch and provider-unavailable states. The root README's feature list, Usage section, and documentation index now surface the new page and the per-loader compatibility table for currency mods.</details> |
