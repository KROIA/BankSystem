# 2.2.2 — In Development

## Security

| Tag | Change |
|---:|---|
| ![bugfix] | The server network overview (`/banksystem serverNetworkInfo`: server addresses, ports and online players) is now really limited to BankSystem admins. In 2.2.0 any player on the master, on a single server or on a trusted slave server could still open it |
| ![bugfix] | A world moved to a newer Minecraft version (for example from 1.21.1) is no longer refused at startup because Minecraft renamed or changed items stored in the bank, such as the chain or enchanted books. Bank items are now upgraded the same way Minecraft upgrades items in chests, and the server log lists renamed items as information instead of warning that balances point at the wrong items. If some items still can't be loaded, the refusal screen lists them as "changed by an update" and says to use the versions that last saved the world, instead of blaming a missing mod |

## Performance

| Tag | Change |
|---:|---|
| ![bugfix] | A server with a large mod pack (tens of thousands of items) no longer freezes on its first start, and is no longer stopped by the watchdog, while BankSystem sets up its item list. Later starts with many items are faster too |

## API

| Tag | Change |
|---:|---|
| ![bugfix] | Async bank API on the master server: calls made from another thread (for example a database callback or a scheduler of another mod) now run on the server thread, so they can no longer change bank data at the same time as the game. Calls from the server thread still run right away. Also, `createBankAsync` and `getOrCreateBankAsync` now refuse blacklisted and invalid items, and `createBankAccountAsync` behaves exactly like `createBankAccount` |
| ![improvement] | The dividend API (`IDividendPayer`) description now matches what it does: `includeCompanyAccount` is ignored (the company's own account never receives a dividend), and calling the API directly does no permission check. `NO_PERMISSION` is never returned by the API itself; a missing permission is only reported when a player starts the dividend in game |
| ![improvement] | Currency binding API: the membership methods (`syncMembership`, `currentMembers`, `canWithdraw`, `isSharedAccount`) are now documented as not called by BankSystem yet. Members of a shared BankSystem account are not synced to the external currency mod (for example a Numismatics Blaze Banker's trust list); this corrects the 2.0.5 notes, which said they were |

## CLI

| Tag | Change |
|---:|---|
| ![bugfix] | `/banksystem symbols reload` now picks up new share symbol images copied into the symbols folder and forgets deleted ones. Before, only `/banksystem symbols add` added images, and deleted ones could still be found |

## UI / UX

| Tag | Change |
|---:|---|
| ![bugfix] | One-time payouts now always need a target. Before, the payout editor could save a one-time payout with Dividend ticked, which never paid anything; the two boxes now exclude each other. A one-time payout that can't be paid is retried less and less often (up to every 5 minutes) instead of every second, and its failure shows in the payout history once (and again only when the reason changes) instead of on every attempt |
| ![bugfix] | Audit screen: the time, type and counterparty columns now show in full instead of being cut off. Balance History: long item names in the item list now end in "..." instead of scrolling back and forth. Payout editor: the target line now uses the free width of its row and ends in "..." (the full target shows as a tooltip) instead of being cut off |
| ![bugfix] | In German, the money items are now called Dollar, matching the $ shown in amounts and the English names. Before, they were called Euro while amounts showed $ |
| ![bugfix] | German texts: spelling fixes (for example "Änderungen speichern", "Bank schließen", "Gesamte Zirkulation", "Unternehmenswährung"). The "Create new bank" button now reads "Neue Bank anlegen" instead of "Bankkonto eröffnen", because it adds an item bank to the account rather than opening a new account |
| ![bugfix] | Sneak + right-click on a Bank Display with an empty hand opens its settings, so you can change what it shows or which account it uses after it has been set up. Before, a set-up display could not be changed, not even by breaking and re-placing it |
| ![improvement] | German players now see many more screens and messages in German: Bank Display setup and the display itself, Balance History, the share editor, Mod Settings (all setting names and tooltips), the Bank Terminal's History button and recipe selection, `/company` replies and admin chat messages. Messages sent by server commands use the server's language |

## Documentation

| Tag | Change |
|---:|---|
| ![improvement] | The guides moved to the new documentation site, [kroia.github.io/BanksystemStockmarketDoku](https://kroia.github.io/BanksystemStockmarketDoku/banksystem/), which covers BankSystem and StockMarket for players, server admins and mod authors. The guide pages in the repository are gone, and the README is now a short overview with a link to the site |

## Internal

| Tag | Change |
|---:|---|
| ![improvement] | The server log now shows progress while BankSystem sets up the item list at server start (a start line with the item count, a progress line about every 5 seconds, and a done line with the number of new items and the time taken), and the same on a slave server while it applies the master's item list, so a long first start on a large mod pack no longer looks frozen |
